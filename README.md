# Proyecyo FP (Tienda de Videojuegos)

Este proyecto se basa en realizar una tienda de videojuegos de momento por CLI, de manera basica.

Tenemos como bases en el proyecto a:
- Producto.java 
Clase contenedora de atributos necesarios para definir un producto y su tipo (el tipo se define mediante su id) 

- Clase videojuegos 
Clase contenedora de los videojuegos de la tienda con nombre y precio ya definido 

- Clase consolas 
Clase contenedora de las consola de la tienda con nombre y precio ya definido 

- Clase Figuras
Clase contenedora de las figuritas de la tienda con nombre y precio ya definido 
- Carrito.java 
El carrito desde el cual el cliente puede añadir, borrar productos, tener diferentes descuentos y demas 

- Factura.java 
Una vez relizada la compra la factura sale y se realiza el pago correspondiente descontando los productos y restandole el sotck correspondiente, el cual se reinicia cada ejecución del programa
